## 五、本次优化做了什么

1. **桌面替换**：编译 Aerial 1.65，包名改成 com.ktcp.launcher.aerial 以通过固件 HOME 前缀白名单；进桌面后延迟 5 秒再跳设置的应用（延迟加在 openBootSource 内部，三条跳转路径都生效）。
2. **停用 22 个系统应用**：含官方桌面、广告、工厂测试、远场调试、智慧家居、无线热点、快捷设置等；保留投屏、输入法、蓝牙、OTA、创维设置。
3. **卸载 4 个顽固包**：ottstatsv2（数据采集）、ott.advert.app（小湃通广告，抢屏保的元凶）、skyappupdate（应用更新）、logcollector（日志收集）。卸载只作用于 user 0，/system 里的原 APK 未删，APK 另存一份在盒子 /sdcard/p3-backup/。
4. **屏保换成 AerialDream**。
5. **看门狗自动补回**：PC 端轮询，发现该停的没停就跑一次优化脚本。

### 卸载为什么能根治

包对 user 0 不存在时，云端的恢复动作会直接抛异常，logcat 里有现成证据：

```
java.lang.IllegalArgumentException: Unknown package: com.starcor.mango
    at ...AppManagerUtils.unHiddenSingleApp
```

### 固件恢复链路（元凶已查明）

```
BOOT_COMPLETED
  → SkyPropretyReceiver（uid 1000，com.skyworthdigital.skycommonpropertymanager）
  → SkyDownloadSystemControlListProcess  联网下载厂商"系统控制列表"
  → AppControlMsg.executeAppControl
  → AppManagerUtils.unHiddenSingleApp
  → setApplicationEnabledSetting(ENABLED)
```

恢复间隔最快 9 秒，开机后约 60 秒执行一次，之后周期再来。列表里还有 useDefaultLauncher 字段，HOME 偶尔被抢回也是它。

### 试过但无效的办法（别再试）

| 办法 | 结果 |
|---|---|
| pm disable --user 0 | Security exception，shell 无权限 |
| pm suspend | 拦不住开机广播，且被拉起后退不出去，6 个包全常驻，多占约 92 MB |
| 停 com.skyworthdigital.upgrade | 照样恢复，upgrade 自己也被恢复，白丢 OTA |
| 停 skycommonpropertymanager | uid 1000 的 BOOT_COMPLETED 拦不住，开机照样下发 |
| 写固件黑白名单 | 值被云端列表覆盖回原值 |
| 改 /etc/hosts 屏蔽域名 | /system 只读挂载，uid 2000 写不进去 |

## 六、常用命令

```bash

```

## 七、遗留项

- **屏保每次开机失效**：广告包已卸载，固件仍把 screensaver_components 写回那个不存在的组件。开机后需跑一次优化脚本（或让看门狗自动补）。
- **语音助手与媒体中心**：仍会被云端恢复，当前靠看门狗在 30 秒内补回。若要彻底处理，可对这两个也走卸载，代价是语音遥控失效、U 盘播放失效。
- **定时启动（com.ktcp.launcher.autostart）当前未安装**：本次开机项里没有它，需要时再单独装。
- **可停未停的候选**：com.android.providers.tv（7.9 MB，原生频道数据，用影视仓看直播时确实用不上）。
