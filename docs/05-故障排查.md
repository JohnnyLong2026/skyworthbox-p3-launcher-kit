# 05 故障排查

## 开机后手动点开设置，会立刻开始跳转倒计时（v4.1 已修）

老版本 `MainActivity` 里有一段"是不是刚开机"的判断，分不清桌面拉起和用户手动打开，
所以开机 4 分钟内手动点一次就会启动倒计时。v4.1 已删除该逻辑：
**arm 只由 Aerial 的 `AutostartBridge` 发起**，设置界面永远不启动倒计时。

升级：重跑 `./scripts/20-build-autostart.sh`，或直接装 `apk/tvautostart-v4.2.apk`。

## 打开设置界面后，原本待弹出的跳转为什么没了

v4.1 起这是**预期行为**：你主动打开设置 = 你要操作，所以会取消那次还没弹出的自动跳转。
想让它继续？关掉设置界面等下次开机即可（每次开机只触发一次）。

## 开机定时启动不弹

按顺序查：

1. **配置是否还在**
   ```bash
   adb shell cat /data/data/com.ktcp.launcher.autostart/shared_prefs/*.xml
   ```
   空的就重设：`./scripts/30-set-autostart.sh <包名> <名称> 5`

2. **是不是刚开机 3 分钟内** —— `AutostartBridge` 用「开机 3 分钟内」+ `BOOT_COUNT` 去重，
   开机后过了 3 分钟才进桌面就不会触发（比如盒子是唤醒而不是真重启）

3. **桌面是不是 Aerial** —— `adb shell cmd package resolve-activity --brief -a android.intent.action.MAIN -c android.intent.category.HOME`
   不是就重跑 `21-build-aerial.sh`

4. **服务有没有起来**
   ```bash
   adb shell ps -A | grep autostart
   adb logcat -s ReminderService AutostartBridge
   ```

## 装完桌面开不了机 / 卡开机动画

原因：官方桌面被停用，但第三方桌面没接管 HOME。

```bash
adb shell pm enable com.skyworthdigital.sky2dlauncherv4
adb shell reboot
```

预防：先跑 `21-build-aerial.sh`（会自动确认 HOME 已解析到自己），再停用官方桌面。
`10-optimize.sh` 默认**跳过**官方桌面就是为了这个。

## `install -r` 显示 Success 但设备上还是旧包

包名不对。编译必须带：

```bash
./gradlew assembleRelease -PlauncherApplicationId=com.ktcp.launcher.autostart
```

否则装成默认的 `com.skyworthdigital.autostart`，成为另一个应用。
多余的包装错了就卸：`adb shell pm uninstall com.skyworthdigital.autostart`

## 组件名报 class not exist

`applicationId` 和 Java 命名空间不一致时，组件全名是**混合**的：

```
com.ktcp.launcher.autostart/com.skyworthdigital.autostart.ReminderService   ✓
com.ktcp.launcher.autostart/.ReminderService                                ✗
com.ktcp.launcher/com.gathin.tvhome.MainActivity                            ✓（CleanYourTV 时代）
```

## 第三方应用收不到广播 / 起不来

侧装的应用默认处于 `stopped` 态，收不到广播也起不来。清一次：

```bash
adb shell monkey -p <pkg> -c android.intent.category.LAUNCHER 1
adb shell dumpsys deviceidle whitelist +<pkg>
```

脚本里已包含。

## `settings get global <key>` 返回 null

经 adb 重定向时常返回 null，不代表没设置。用：

```bash
adb shell settings list global | grep <key>
```

## `adb pull` 报 "failed to stat remote object ... PortableGit/..."

Git Bash 把远程路径转成了 Windows 路径。用 `MSYS_NO_PATHCONV=1 adb pull ...`，
或直接用 `lib.sh` 里的 `adb_pull`。

## 盒子突然连不上

多半是**休眠**了 —— 休眠时 ADB 完全无响应，网关会回"无法访问目标主机"。
遥控器按一下唤醒再连。不是脚本问题。

## 桌面图块图标换了没效果

Aerial 读的是 `android:banner`（320×180 横图），不是 `ic_launcher`。改 `res/drawable-nodpi/banner.png`。

## 天气显示的城市不对

Aerial 默认按 IP 猜（会猜成武汉）。跑 `./scripts/31-set-weather.sh 北京市` 固定城市。

## 屏保又变回创维的广告了

不是设置没生效，是固件每次开机都会把 `screensaver_components` 写回
`com.skyworthdigital.ott.advert.app/...ScreenSaverService`；重装 Aerial 也会重置一次。

```bash
adb shell settings get secure screensaver_components   # 看当前值
./scripts/10-optimize.sh                               # 补回（会调 restore_dream）
```

只想改屏保、不想跑整套优化时：

```bash
source scripts/lib.sh && conn && restore_dream
```

Aerial 1.49 起还有一层兜底：系统 dream 拉不起来时，它自己显示屏保。

## 完全还原

```bash
./scripts/40-restore.sh            # 参数 + 应用 + 官方桌面
./scripts/40-restore.sh --uninstall  # 卸掉我们装的两个应用
```
