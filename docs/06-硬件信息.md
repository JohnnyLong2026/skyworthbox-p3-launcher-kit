# 06 硬件信息（创维小湃 P3 / Q5001）

`adb shell` 实测采集，2026-10-24。

同型号盒子的参数基本一致，**序列号、MAC 属于设备唯一标识，本文不公开**；
你可以在自己盒子上用下面第二条命令读出来。

```bash
adb -s <盒子IP>:5555 shell getprop ro.serialno          # 序列号
adb -s <盒子IP>:5555 shell ip link show eth0            # MAC
```

> 这是 2020 年前后的入门级盒子：2GB 内存跑 Android TV 桌面会有点吃力，
> 这也是后面所有优化都要围绕「省内存、少动画、少常驻」来做的原因。

## 关于 32 位用户空间

`ro.product.cpu.abi = armeabi-v7a`。装应用时注意：

- 只带 `arm64-v8a` so 库的 APK 会安装失败或运行崩溃
- 编译时 `minSdk` 可以设 21+，但不要只打 64 位包

## 硬件解码

支持 H.265 / H.264 / VP9 等硬解，存在 `avc.secure` 安全解码通道。

## 固件特性（影响改造方案）

- **HOME 前缀白名单**：`com.skyworthdigital.sky2dlauncher` / `com.ktcp.launcher` /
  `com.android.provision` / `com.skyworthdigital.bluetooth.settings`，前缀匹配
- **拦截第三方开机广播**：`BroadcastQueue: Block auto start app from broadcast`
- `adb root` 不可用（"adbd can't run as root"），无 su，`/system` 只读
- `pm disable-user` **可用**（shell 用户无需 root）
- 待机约 3 分钟无操作，`com.skyworthdigital.skypowermanager/.AdActivity` 会起来
- 屏保默认是广告服务 `com.skyworthdigital.ott.advert.app`
- 预装搜狗输入法 `com.sohu.inputmethod.sogou.tv`
