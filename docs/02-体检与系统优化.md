# 02 体检与系统优化

## 体检（只读，不改任何东西）

```bash
./scripts/00-doctor.sh
```

输出：设备信息、存储、内存 Top、HOME 归属、第三方应用及状态、已停用清单、定时启动配置、系统参数。

## 优化做了什么

```bash
./scripts/10-optimize.sh              # 完整优化
./scripts/10-optimize.sh --clean      # 只清垃圾和缓存
```

### 1. 停用不用的常驻应用（`config/disable-list.txt`，18 个）

| com.skyworthdigital.voiceassistant | 语音助手（17.8MB） |
| com.skyworthdigital.skymediacenter | 本地海报墙（14.2MB） |
| com.skyworthdigital.autotest | 工厂自检（6.5MB） |
| com.skyworthdigital.ott.guide | 开机引导 |
| com.skyworthdigital.smarthome | 智能家居 |
| com.skyworthdigital.miracast | 无线投屏（另保留 mediarender 投屏） |
| com.skyworthdigital.softap | 热点 |
| com.skyworthdigital.skycleandisk | 清理工具 |
| com.skyworthdigital.optimization | 优化工具 |
| com.skyworthdigital.remotedebug | 远程调试 |
| com.skyworthdigital.skywechatclient | 微信互联 |
| com.mipt.store / com.jd.smartservicetwo | 应用商店 / 京东服务 |

| com.softwinner.dragonbox / agingdragonbox | 工厂测试 |

用的是 `pm disable-user --user 0`（**可逆**，不是卸载）。停用后桌面图标会消失，随时 `pm enable` 恢复。
这些包都没有 LAUNCHER 入口，停用不影响桌面图标。

> 官方桌面 `com.skyworthdigital.sky2dlauncherv4` 默认**跳过**：
> 如果在第三方桌面接管前停掉它，系统会卡在开机动画。确认 HOME 已是第三方桌面后，
> 用 `./scripts/10-optimize.sh --with-launcher` 才停它（`21-build-aerial.sh` 会自动处理）。

### 2. 系统参数

### 3. 换掉广告屏保

系统默认屏保是 `com.skyworthdigital.ott.advert.app`（**广告**）。
装了 Aerial 之后换成 `com.ktcp.launcher.aerial/app.orchard.tv.dream.AerialDream`（航拍屏保）。
原值备份在 `config/backup-screensaver.txt`，`40-restore.sh` 会还原。

> **这不是一次性设置。** 固件在每次开机时都会把 `screensaver_components` 写回广告组件，
> 重装 Aerial 也会重置一次。所以重启后如果屏保又变回广告，跑一遍
> `./scripts/10-optimize.sh` 即可（内部调用 `lib.sh` 的 `restore_dream()`）；
> 装完 Aerial（`21-build-aerial.sh`）也会自动补回。
> 备份文件只记录出厂值，反复执行不会把广告值当成"原值"覆盖掉。

### 4. 清垃圾

- 删掉调试期间留在 `/sdcard` 的截图（本次清理了 74 张 / 42MB）
- `pm trim-caches` 回收各应用缓存
- `am force-stop com.android.provision`（开机向导，`device_provisioned=1` 后不再需要）
- 杀掉已停用应用残留的进程（`disable-user` 不会杀已有进程）

## 实测效果

| 指标 | 优化前 | 优化后 |
|---|---|---|
| MemAvailable | 1.1829 GB | 1.2055 GB |
| 常驻应用进程 | 28 个 | 明显减少 |

内存大头是影视仓（125MB）和投屏服务（45MB），这两个**保留**了 —— 是用户在用的功能。

## 判断"是不是系统应用"

`pm list packages -s` 在这台机器上**不准**：它把预装在 `/data/app` 的厂商应用也算成系统包
（voiceassistant、shortcutkeyssetting、skycommonpropertymanager、mipt.store 等都是）。
要判断得看 `codePath`：`/system/app` 或 `/system/priv-app` 才是真系统应用。
