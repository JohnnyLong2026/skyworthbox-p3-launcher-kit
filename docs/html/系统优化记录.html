六、回滚方式

所有操作用的都是「停用」（pm disable-user），不是卸载，数据和 APK 都还在。工作区已生成一键回滚脚本：

bash restore-presetapps.sh

只恢复某一个包，直接指定包名即可：

adb connect 192.168.1.100:5555
adb shell pm enable com.skyworthdigital.voiceassistant
唯一需要小心的一条：如果哪天要恢复官方桌面 com.skyworthdigital.sky2dlauncherv4，必须先 pm enable 再 reboot，顺序颠倒会卡在开机画面。
