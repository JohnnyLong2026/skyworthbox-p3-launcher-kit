二、为什么包名不是 app.orchard.tv

这台创维盒子在系统框架层维护了一份桌面包名前缀白名单（logcat 里能看到 allow home apk / block home apk）。只有前缀命中的包才能成为默认桌面，其余即便声明了 HOME 也会被系统忽略。

app.orchard.tv 不在名单里，直接装官方包无法接管桌面。而 com.ktcp.launcher 是白名单里的前缀且当前空闲，所以 Aerial 以 com.ktcp.launcher.aerial 的身份安装 —— 只改安装包名，Java 命名空间保持 app.orchard.tv 不动，功能和后续维护都不受影响。

这也是之前 CleanYourTV 能用 com.ktcp.launcher 当桌面的同一套原理。区别是它俩不能同时占用同一前缀：CleanYourTV 用的是 com.ktcp.launcher 本身，Aerial 用的是它的子前缀，两者互不冲突。

三、定时启动怎么保留的

原来的「开机 N 秒后弹窗并跳转」是挂在 CleanYourTV 桌面里的钩子，换桌面后必然失效。这套固件又封死了所有第三方开机广播（Block auto start app from broadcast），App 自己无法在开机时醒来。所以改成由 Aerial 交出这个时刻：

开机→ Aerial 作为桌面启动→ 判定「本次开机的首次进入」
BOOT_COUNT + 3 分钟窗口→ 拉起定时启动服务→ 延迟 N 秒弹窗→ 跳转目标 App

只改了两处代码：Aerial 侧新增 system/AutostartBridge.kt（约 40 行，每次开机只触发一次），定时启动侧把服务改成可被外部唤起并识别 ACTION_ARM。你的延时秒数和目标 App 都沿用原来的配置，没有变化。

实测通过：重启后 Aerial 自动成为桌面 → 服务被唤起 → 浮层盖在 Aerial 上倒计时 →「1 秒后自动跳转至 影视仓」→ 准时跳转。按遥控器任意键仍可取消。

四、桌面怎么用

操作效果
方向键左右在第一排 App 之间移动
往下展开全部 App
第一排按上打开控制中心（信号源、网络、设置、音量、亮度、个性化）
长按 OK / 菜单键整理：移动、建文件夹、隐藏、卸载
手机扫码个性化里有二维码，手机端可拖拽排序、改名、换图标、上传壁纸
闲置 10 秒壁纸后面开始播航拍动态效果，按任意键停在当前画面

第一排最左边那个灰色渐变图标是系统里某个没有名称的组件，长按 OK 就能隐藏掉，不影响任何功能。

五、注意事项

不要用 Aerial 控制中心里的「检查更新」。它下载的是官方包 app.orchard.tv，装上后会变成另一个独立应用，而不是替换当前这个定制版，桌面还会留在旧版本上。想升级时告诉我，我按同样方式重新编译一版。
  • 已按官方脚本补齐授权：精确定位（读 Wi-Fi 名称）、WRITE_SECURE_SETTINGS、悬浮窗、改亮度、安装未知应用、通知监听，并对 APK 做了 speed 编译优化。
  • 原 CleanYourTV 桌面没有卸载，只是不再是默认桌面。万一 Aerial 出问题，执行下面的命令就能回到旧桌面。
  • 系统的广告屏保（待机时的推广画面）仍然存在。Aerial 自带的航拍屏保可以在设置里启用；若想让待机也播航拍，需要把它的 Dream 组件设成系统屏保 —— 你需要的话我来做。

六、回滚

adb connect 192.168.1.100:5555
adb shell cmd package set-home-activity com.ktcp.launcher/com.gathin.tvhome.MainActivity
adb shell input keyevent KEYCODE_HOME

要彻底回到没有 Aerial 的状态，卸载它即可（不影响定时启动，钩子会自动跳过不存在的包）：

adb shell pm uninstall com.ktcp.launcher.aerial
源码位于 aerial-tv/，改动只有 app/build.gradle.kts（包名）、system/AutostartBridge.kt（新增）、MainActivity.kt（一行调用）。APK 在项目根目录。
